# UPSA Student Request System (UPSASRS)

A web-based system designed to digitize and streamline student service requests such as transcripts and introductory letters.

## 🚀 Live Demo
https://upsasrs.netlify.app

## 🎯 Problem
- Students lack visibility into request status  
- Processes are fragmented and unclear  
- Payment and submission steps are confusing  
- Admins struggle with tracking and consistency  

## 💡 Solution
- Multi-step guided request flow  
- Status tracking system  
- Manual payment validation with proof upload  
- Admin dashboard for processing requests  

## 🧠 Key Design Decisions
- Multi-step form to reduce cognitive load  
- Manual validation aligned with existing UFIS workflow  

## 🛠 Tech Stack
- HTML  
- CSS  
- JavaScript  
- Netlify (deployment)

## 📌 Outcome
A fully functional system improving transparency, structure, and efficiency in student request workflows.
